\# Shift Dynamics - Team Roles and Responsibilities



\## Project Manager



Responsibilities:

\- Project planning

\- Task assignment

\- Requirements tracking

\- Timeline and milestone management

\- Git and pull request coordination

\- Progress tracking

\- Testing and release coordination

\- Team communication

\- Documentation management



\## Backend Developer



Responsibilities:

\- REST API development

\- Business logic

\- Authentication and authorization

\- Backend validation

\- API integration



\## Frontend Developer



Responsibilities:

\- User interface development

\- Frontend components

\- API integration

\- Client-side validation

\- Responsive design



\## Database Developer



Responsibilities:

\- Database design

\- Tables and relationships

\- Constraints

\- Seed data

\- Database maintenance



\## QA / Testing



Responsibilities:

\- Test planning

\- Functional testing

\- API testing

\- Bug reporting

\- Regression testing



\## Team Responsibilities



All members must:

\- Follow the Git workflow

\- Work on assigned branches

\- Create pull requests

\- Communicate blockers

\- Meet agreed deadlines

\- Review assigned work

\- Maintain project quality
