\- Unit tests

\- API testing

\- Integration testing

\- Bug reports

\- Regression testing



\## Workflow

1\. Create a feature branch.

2\. Implement the assigned task.

3\. Test locally.

4\. Push the branch.

5\. Create a Pull Request to `main`.

6\. Review the PR.

7\. Merge only after approval and successful testing.
